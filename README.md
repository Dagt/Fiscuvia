# Fiscuvia

**Todo tu despacho, una sola vía.**

SaaS para gestión integral de despachos contables en México: contribuyentes, obligaciones, evidencia documental, tareas, honorarios y, por fases, CFDI e integración con el SAT.

> Estado: etapa de definición de producto y arquitectura; **no existe todavía una aplicación funcional ni un sistema listo para almacenar datos fiscales reales**.

La documentación funcional, técnica, de seguridad y diseño visual se desarrolla mediante pull requests y se revisa antes del merge. No almacenar credenciales SAT, e.firma, RFC reales, XML, PDF sensibles ni secretos en este repositorio.
