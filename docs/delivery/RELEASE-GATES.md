# Puertas de aceptación
G0: visión, PRD, ADR, riesgos, mockups/diseño e issues revisados.
G1: identidad, autorización, RLS, API y DB demostrados con dos despachos ficticios.
G2: alta de contribuyente, período, obligación, tarea y evidencia trazable.
G3: revisión/presentación/pago separados, documentos, honorarios y reportes.
G4: UX/visual de todas las pantallas del MVP, accesibilidad, backups y restore, telemetría.
G5: revisión de seguridad apropiada, UAT de contadores, privacidad/contratos y pruebas piloto con datos sintéticos.
G6: piloto limitado con usuarios autorizados, monitoreo y respuesta a incidencias, sin vulnerabilidades críticas conocidas.
No asignar fechas ficticias ni afirmar disponibilidad SAT antes de pruebas y consentimiento.
